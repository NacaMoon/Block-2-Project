# Caffeine Guard — Capstone Archive
This repository hosts a clean, public snapshot of my CS capstone project **Caffeine Guard** for reference and reuse.

## Overview
What it does: A mobile app that helps you track caffeine and hydration, visualize trends, and get smart reminders (with quiet hours).  
Why it exists: To promote healthier daily habits through lightweight logging, clear charts, and privacy-respecting defaults.

## Key Features
- Log beverages with caffeine amounts and timestamps
- Daily/weekly charts for intake and hydration trends
- Custom reminders (quiet hours supported)
- Offline-first storage; sync planned in later phases
